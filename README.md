# **Bazaar-Connect**

- **Bazaar-Connect** is an inspired B2B surplus exchange platform project founded by three people.

- It was built for hospitality ecosystems around the local area, connecting with hotels, resorts
and event revenues with charities, farmers, and recycling partners.

- The main goal is to ensure that surplus food and supplies are redistributed and not wasted.

- In simple terms, the expansion of this idea was to use real-time technology, offline access, and
circular economy thinking to make sure everyone will get involved.

The project is a prototype, it only contains the core concepts of what was focused on.

I mainly focused on the backend while one of my other teammates focused on the frontend.
